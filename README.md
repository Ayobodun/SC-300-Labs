# 🧩 Lab Index

| Lab | Project | Description |
|------|----------|-------------|
| 01 | Administrative Units | Delegated administrative control for specific users and groups within Microsoft Entra ID. |
| 02 | Self-Service Password Reset (SSPR) | Configured password reset policies and tested end-user password recovery workflows. |
| 03 | Dynamic Groups | Created rule-based groups that automatically manage membership based on user attributes. |
| 04 | Enterprise Applications & Single Sign-On | Integrated applications and configured SSO for seamless user authentication. |
| 05 | Entitlement Management | Created access packages and approval workflows to govern resource access. |
| 06 | Access Reviews | Implemented periodic access reviews to validate group and application assignments. |
| 07 | Lifecycle Workflows | Automated joiner, mover, and leaver processes for user lifecycle management. |
| 08 | Conditional Access | Enforced security controls using MFA, location-based policies, and legacy authentication blocking. |
| 09 | Authentication Methods | Configured Microsoft Authenticator, Temporary Access Pass (TAP), and passwordless authentication. |
| 10 | Privileged Identity Management (PIM) | Implemented Just-In-Time administration and role activation approval workflows. |
| 11 | Guest Users & External Identities | Managed B2B collaboration and external user access to organizational resources. |
| 12 | App Registrations & Enterprise Apps | Created app registrations, configured API permissions, and managed enterprise applications. |
